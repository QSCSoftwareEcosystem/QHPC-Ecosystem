# Tool developer and author attribution

This page records human attribution that can be verified from each capability's
pinned source revision or a publication linked by that revision. It deliberately
distinguishes named developers and publication authors from names found only in
repository commit metadata. A person is not labeled as the current maintainer
unless the pinned project documentation explicitly assigns that role.

this page: **Vicente Leyton-Ortega**, as shown in the
[EQO repository history](https://github.com/QSCSoftwareEcosystem/QHPC-Ecosystem/commits/main).
