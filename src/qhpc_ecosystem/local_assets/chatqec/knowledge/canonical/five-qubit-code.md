# Five-Qubit Code

The five-qubit code is the smallest possible quantum code that corrects an
arbitrary single-qubit error — a $[[5,1,3]]$ code. It is the "perfect" code,
saturating the quantum Hamming bound, and a canonical example of a **non-CSS**
stabilizer code.

## Why five is the minimum

The quantum Hamming bound for a non-degenerate code correcting $t=1$ error on
$n$ qubits requires

$$
2^{n-k} \ge \sum_{j=0}^{t} \binom{n}{j} 3^{j} = 1 + 3n.
$$

For $k=1$, $t=1$ this gives $2^{n-1} \ge 1 + 3n$, whose smallest solution is
$n = 5$ (where $16 = 16$). The five-qubit code meets this with equality, so it is
**perfect**: the $2^4 = 16$ syndromes are in exact one-to-one correspondence with
the $1 + 3\cdot 5 = 16$ single-qubit errors (see [[knill-laflamme]] and
[[nkd-notation]]).

## Stabilizers

Four generators, generated by cyclic shifts of one Pauli string:

$$
g_1 = XZZXI,\quad g_2 = IXZZX,\quad g_3 = XIXZZ,\quad g_4 = ZXIXZ.
$$

Because the generators mix $X$ and $Z$ on the same qubits, the code is **not** a
CSS code — bit- and phase-flip protection are entangled rather than separable.

## Properties

- **Non-degenerate:** every correctable single-qubit error has a distinct
  syndrome.
- **Cyclic:** invariant under a cyclic permutation of the five qubits.
- Used heavily as a minimal example and in early fault-tolerance and
  entanglement-purification demonstrations.
